# 音読スナップ

教科書や教材の「実際に音読するページ」を登録して、タブレットですぐ音読できるようにするシンプルな音読支援アプリです。

## コンセプト

「教材を登録する」→「読むページを登録する」→「音読する」→「記録を残す」という流れを、できるだけ少ない操作で行えるようにしています。

トップ画面には登録済みの教材を表示します。教材を選ぶと、その教材に登録したページだけを開くことができます。

教科書全体を登録するのではなく、実際に音読するページだけを登録して使う想定です。

## 主な機能

- 登録済み教材をトップ画面から選択
- 教材ごとの音読ページ管理
- カメラでページを撮影して登録
- 写真ライブラリからページを登録
- PDFを読み込み、各ページを画像に変換してまとめて登録
- 登録したページを端末内に保存
- 音読中にページをめくるように切り替え（左右ボタン・スワイプ対応）
- ページめくり機能が利用できない場合も、1ページ表示へ自動で切り替えて音読を続けられる
- 音声を録音
- 録音した音声を確認・再生
- 音読記録の一覧表示
- 録音データの保存・削除
- ページの並べ替え・削除
- 教材名の変更
- 登録写真を表示用に縮小して保存し、端末容量を節約
- 教材写真・音声は端末内に保存（ナビキャラ画像の表示にはネット接続が必要）

## データの保存について

音読スナップは、サーバーやデータベースへ教材写真・音声を送信する仕組みを使用していません。

教材のページ画像や音読記録は、ブラウザの IndexedDB を利用して使用している端末内に保存します。写真ライブラリから登録した画像は、表示に必要な範囲で長辺最大 2200px の JPEG に変換して保存し、端末容量の使いすぎを抑えます。PDFはPDF.jsでページごとに画像へ変換してから保存します。PDF.jsの読み込みにはCDNへのインターネット接続が必要ですが、選択したPDFや変換後のページ画像を外部へ送信することはありません。

なお、ナビキャラのイラストは別リポジトリから読み込むため、アプリの初回表示やイラスト表示にはインターネット接続が必要です。教材写真・音声を外部へ送信する仕組みはありません。

そのため、同じ端末・同じブラウザで利用する場合は、登録したページを毎回撮影する必要はありません。

ブラウザのデータを削除した場合や、別の端末・ブラウザへ移行した場合は、保存データが利用できなくなることがあります。

## カメラ・マイクについて

ページ登録では端末のカメラを使用します。

音読記録ではマイクを使用して音声を録音します。

カメラ・マイクへのアクセスは、ブラウザの許可が必要です。

## 使い方

### 1. 教材を追加する

トップ画面の「＋ 教材を追加」から教材名を登録します。

例：

- やまなし
- 国語 六年
- 〇〇の音読

### 2. 音読するページを登録する

教材を開き、「ページを追加」からカメラまたは写真を使ってページを登録します。

ページ番号などを設定して、読む順番に並べます。

### 3. 音読する

教材から登録済みのページを開き、音読を開始します。

音読中はページを切り替えながら録音できます。

### 4. 記録を確認する

音読後は録音を確認できます。

「音読の記録を見る」から、これまでの記録を再生・保存・削除できます。

## 技術構成

- HTML / CSS / JavaScript
- GitHub Pages で動作
- ページめくりライブラリはリポジトリ内の `vendor/` から読み込み、通常の音読画面では外部CDNに依存しない
- IndexedDB による端末内データ保存
- MediaDevices API によるカメラ・マイク利用
- MediaRecorder API による音声録音
- 外部サーバー・バックエンド不要
- APIキー不要

## プライバシー

教材画像・音声は、アプリのサーバーへアップロードするのではなく、利用している端末のブラウザ内に保存します。

学校で使用する場合は、端末の共有状況やブラウザのデータ消去設定などを確認してください。

## 著作権について

本アプリは、利用者が自分で使用する教材の必要なページを撮影し、音読するための補助ツールとして設計しています。

教科書・教材そのものの著作権は、それぞれの権利者に帰属します。

撮影した教材画像を第三者へ配布・公開したり、教材本文をアプリへ組み込んで再配布したりすることを目的としていません。学校で利用する場合も、学校教育に関する著作権法上の扱いや、各教材の利用条件を確認してください。

## ライセンス

このリポジトリのコードおよびオリジナルの教材・デザイン・画像・キャラクター等について、学校・家庭での非営利利用を想定しています。

商用利用、販売、再配布、オリジナル素材単体での二次配布等については制限があります。詳細な条件は、今後整備するライセンス文書を確認してください。

## 対象

主に小学校での音読活動、家庭学習、授業中の音読練習などを想定しています。

「毎回教科書を撮り直す」のではなく、「一度登録した必要なページを、必要なときにすぐ開く」ことを目的としたアプリです。


## ページ表示と切り替え

音読画面では、登録したページをめくるような動きで切り替えます。画面上の左右ボタン、録音パネルの「次のページ →」、または横スワイプで移動できます。ページ表示用のライブラリは `vendor/` 内のファイルを使うため、通常の音読では外部CDNに接続しません。

万一、ページめくり機能を読み込めない場合は、写真を1枚ずつ表示する予備モードに切り替わります。画像が見えなくなって音読を続けられない状態を避けるための仕組みです。ページ写真の保存形式は、iOS Safariで扱いやすいよう、端末内保存時に画像データをバイナリ形式へ変換し、読み出すときに画像へ戻します。


## PDFの取り込み

ページ管理画面の「PDFを選ぶ」からPDFを選ぶと、各ページを画像に変換して音読ページとして登録します。1回につき最大80ページまで登録できます。PDF.jsをCDNから読み込むため、PDF取り込み時はインターネット接続が必要です。PDFファイル自体は外部サーバーへアップロードせず、ブラウザ内で処理します。
